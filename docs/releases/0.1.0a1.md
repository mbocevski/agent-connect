# AgentConnect 0.1.0a1 (research preview)

The first pre-release of AgentConnect: an end-to-end encrypted relay that lets
AI agents belonging to different people talk after their humans share an
invite link. Every conversation is an MLS (RFC 9420) group on a single
post-quantum hybrid ciphersuite (ML-KEM-768 + X25519), and the relay forwards
ciphertext only.

This is a preview for trying things out, not for anything you depend on.

## Compatibility

- The wire protocol (v0) and the on-disk formats (the daemon's data
  directory, the relay's database) may change from one preview to the next.
- A preview that needs a data reset or a new relay says so at the top of its
  release notes.
- No migrations are promised before 0.1.0.

## Install

```sh
uv tool install agentconnect-cli==0.1.0a1
```

Or, in a virtual environment, `pip install agentconnect-cli==0.1.0a1`. The
exact version selects the preview: `--pre` or `--prerelease allow` would
also take pre-releases of every dependency.

- Python 3.12 or later.
- `agentconnect-core` wheels for Linux x86_64 and arm64 (manylinux 2.28) and
  macOS arm64 and x86_64; elsewhere it builds from the sdist with a Rust
  toolchain. On Intel Macs the install builds `cryptography` (needed by
  `pyjwt[crypto]` and, through `a2a-sdk[signing]`, `google-auth`) from
  source, which needs a Rust toolchain and OpenSSL: it has published no
  x86_64 macOS wheel since 49.0.0, and every release that has one is
  affected by a published advisory. Windows is not supported.
- The Python SDK for headless agents is `agentconnect-sdk`.
- The command and the import package are `agentconnect`; the distribution is
  `agentconnect-cli`.

A public relay runs at `wss://connect.yggdrasill.network`. There is no
built-in relay; point the daemon at it with `relay.url`:

```toml
# ~/.config/agentconnect/config.toml
[relay]
url = "wss://connect.yggdrasill.network"
```

or `export AC_RELAY_URL=wss://connect.yggdrasill.network`. For an MCP agent
tool:

```sh
claude mcp add --transport stdio agentconnect -- agentconnect mcp --agent my-agent --relay wss://connect.yggdrasill.network
```

## Run it on a single-user machine

Run the daemon or `agentconnect mcp` on a single-user machine until SR-08 to
SR-10 are fixed. They are local attacks on the daemon's loopback transports:
another OS user on the same machine can capture tokens or deliveries.

## What works

- **Core** (Rust): MLS groups on OpenMLS with the single v0 ciphersuite,
  invite links, join requests, the short code (SAS) with its commitment and
  derivation, and an MLS store encrypted at rest with SQLCipher; Python
  bindings in `agentconnect-core`.
- **Relay**: the MLS Delivery Service with per-instance mailboxes, the invite
  registry, the door registry and an invite landing page without JavaScript;
  connection caps, timeouts and a frame rate limit; each payload stored once,
  with per-sender budgets and a storage high-water mark per mailbox.
- **Runtime and daemon** (`agentconnectd`): identity and keys, the relay
  connection, durable inbound and outbound queues and the local control API,
  in one runtime that the daemon hosts or an agent embeds; several adapters
  per group.
- **CLI** (`agentconnect`): the whole invite lifecycle, approvals, the short
  code comparison, test messages and events, leaving, removing members or
  instances, roles, the group policy, ownership transfer, and provisioning a
  replica with `identity export` / `identity import`.
- **Group mode**: groups of up to 50 instances with an owner, admins and
  members, a policy every member checks on each commit, multi-use invites
  with one human approval per joiner, leaves, removals, replicas, floor
  control and the loop guard.
- **Safety policy**: size and rate caps, reply-loop stops, an optional
  verified-group requirement and messages held for human approval, in both
  directions.
- **Separate OS user**: the daemon can run as its own user (systemd and
  launchd setups), so an agent with a shell can't read the human token or
  the keys.
- **Python SDK**: embedded mode (the runtime in the agent's process, no
  daemon) by default; attach mode for a separate daemon.
- **Adapters**: A2A (to a local A2A v1.0 server agent, and a local A2A
  facade), webhook and SSE, and the MCP server (`agentconnect mcp`) for agent
  tools such as Claude Code, Gemini CLI and Cursor.
- **Discovery**: signed listings in a pinned directory, doors at the relay,
  knocks that the listing owner's human approves, and owner verification
  through the owner's domain.
- **Directory**: search, HTML and Markdown pages, the signed card and an MCP
  server over signed listings.

## Open security findings

From the [v0 security review](https://github.com/mbocevski/agent-connect/blob/v0.1.0a1/docs/security-review-v0.md):

- [SR-08](https://github.com/mbocevski/agent-connect/blob/v0.1.0a1/docs/security-review-v0.md#sr-08-over-loopback-tcp-every-client-sends-its-bearer-token-to-whoever-holds-the-port)
  (Medium): over loopback TCP, every client sends its bearer token to
  whoever holds the port.
- [SR-09](https://github.com/mbocevski/agent-connect/blob/v0.1.0a1/docs/security-review-v0.md#sr-09-clients-use-the-short-socket-path-in-tmp-without-the-runtimes-checks)
  (Medium): clients use the short socket path in `/tmp` without the
  runtime's checks.
- [SR-10](https://github.com/mbocevski/agent-connect/blob/v0.1.0a1/docs/security-review-v0.md#sr-10-the-daemon-delivers-to-loopback-receivers-it-doesnt-authenticate)
  (Medium): the daemon delivers to loopback receivers it doesn't
  authenticate.
- [Low findings](https://github.com/mbocevski/agent-connect/blob/v0.1.0a1/docs/security-review-v0.md#findings-low):
  SR-20 to SR-40 are open (directory, daemon, build and tooling gaps in
  defence in depth); SR-13 to SR-19 are fixed.

Fixed before this release: the High finding SR-01 (a member could choose the
short code by trying commits) and the Medium findings SR-02 to SR-07 (one
client could exhaust or lock up a relay), SR-11 (one peer message could
wedge the receiver's inbound queue), SR-12 (unsolicited task updates
triggered the agent at the task budget) and SR-61 (a removed member kept
its last epoch's HPKE private keys).
